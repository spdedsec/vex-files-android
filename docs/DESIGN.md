# VEX Files Design Notes

## Swiss direction

Use hierarchy, alignment, negative space, type scale, and strict grids to create personality instead of adding decoration.

### Typography

Primary UI text uses the Android system sans face to stay lightweight and portable. Utility labels use the system monospace face. The visual target is a Helvetica/Neue-Helvetica-like neutral grotesk without shipping proprietary font files.

### Geometry

- mostly square controls
- no pill-shaped controls
- no soft cards
- thin separators
- strong left alignment
- dense rows
- short labels

### Color

Black is the field. Warm off-white is the information layer. Red is the action/exception layer.

Use red sparingly. A red button should mean "this changes something" rather than "this is branding".
